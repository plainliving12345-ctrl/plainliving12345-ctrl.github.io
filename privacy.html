Privacy Policy

Channel Helper · Last updated November 5, 2026

Channel Helper is a private tool used only by the owner of the YouTube channels it is connected to. It uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What it accesses

  • Public comments and replies on the owner's own YouTube channels, and the titles, descriptions and public view counts of those channels' videos.
  • When the owner connects a channel with Google sign-in, permission to post comment replies as that channel (scope youtube.force-ssl).
  • The ID and name of the YouTube channel chosen at sign-in. It is read once, when the channel is connected, and used only to show which channel is connected. The app does not read the Google account's email address or profile.

How it is used

  • To show the owner new comments, translate them, and draft and post replies on the owner's own channels. Unless the owner turns this off in the app, it also posts a short reply by itself to simple friendly comments (such as thanks or praise); every other comment waits for the owner.
  • To summarize what viewers ask for and feel, so the owner can plan future videos.
  • To translate comments, draft replies and write those summaries, the text of a comment, the replies under it, and the video's title and description are sent to Anthropic's Claude API. No other translation or AI service is used. Anthropic's handling of that data is described in the Anthropic Privacy Policy.
  • Data is never sold, shared for advertising, or used for any other purpose. No one other than the owner and the service providers named above receives the data.

Google API Services User Data Policy

Channel Helper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular, Google user data is used only to provide the comment-management features described on this page, is not used for advertising, and is not transferred to anyone except as needed to provide those features (the service providers named above), to comply with law, or with the owner's explicit consent.

Where it is stored and for how long

  • Comments, drafts and sign-in tokens are stored only in the app's data folder on the owner's own computers. That folder is inside the owner's personal Microsoft OneDrive, which keeps the owner's two computers in sync. The viewer summaries (without commenters' names) are saved as notes in the owner's own project folders on the same computers. There is no Channel Helper server or database.
  • Saved comments are kept for at most the last 600 comments and can be deleted by the owner at any time.
  • Stored comments are refreshed from YouTube about every 3 hours while the app is running, and whenever the owner presses "check now".
  • Sign-in tokens are kept until the owner disconnects the channel or revokes access (see below).

Removing access and deleting data

The connection can be removed at any time in the app, or at Google Account → Third-party connections. After access is removed, the stored sign-in token stops working; "Disconnect" in the app also deletes it from the owner's computer. Saved comments and drafts are kept in one file, data/comments.json, inside the app's folder; deleting that file (or the whole data folder) deletes them.

Changes to this policy

If this policy changes, the updated version is published on this page with a new "Last updated" date.

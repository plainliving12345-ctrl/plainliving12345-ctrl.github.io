Privacy Policy

Channel Helper · Last updated November 5, 2026

Channel Helper is a private tool used only by the owner of the YouTube channels it is connected to. It uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What it accesses

  • Public comments and replies on the owner's own YouTube channels, and the titles and descriptions of those channels' videos.
  • When the owner connects a channel with Google sign-in, permission to post comment replies as that channel (scope youtube.force-ssl).
  • The basic profile of the signed-in Google account (channel name and ID), used only to show which channel is connected. [TO CONFIRM: delete this item if the app does not read the account's profile or channel list.]

How it is used

  • To show the owner new comments, translate them, and draft and post replies on the owner's own channels.
  • To draft replies, the text of a comment and the video's title and description are sent to Anthropic's Claude API. Anthropic's handling of that data is described in the Anthropic Privacy Policy. [TO CONFIRM: if translation uses a different service (for example a translation API), name it here too.]
  • Data is never sold, shared for advertising, or used for any other purpose. No one other than the owner and the service providers named above receives the data.

Google API Services User Data Policy

Channel Helper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular, Google user data is used only to provide the comment-management features described on this page, is not used for advertising, and is not transferred to anyone except as needed to provide those features (the service providers named above), to comply with law, or with the owner's explicit consent.

Where it is stored and for how long

  • Comments, drafts and sign-in tokens are stored only on the owner's own computers. There is no Channel Helper server or database.
  • Saved comments are kept for at most the last 600 comments and can be deleted by the owner at any time.
  • Stored comments are refreshed from YouTube each time the app checks for new comments. [TO CONFIRM: how often the app refreshes, e.g. "every time it is opened" or "every 30 days at most".]
  • Sign-in tokens are kept until the owner disconnects the channel or revokes access (see below).

Removing access and deleting data

The connection can be removed at any time in the app, or at Google Account → Third-party connections. After access is removed, the stored sign-in token stops working; "Disconnect" in the app also deletes it from the owner's computer. Saved comments and drafts can be deleted from within the app, or by deleting the app's data folder.
